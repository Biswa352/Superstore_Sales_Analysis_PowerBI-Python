# Superstore Sales Analysis — Case Study

## 1. Overview

I used the Sample Superstore dataset to explore sales performance across regions, product categories, and months. I built an interactive report in Power BI and added a Python visual with Matplotlib to compare average sales per order line by category.

The goal was to identify where sales were strongest, which categories contributed most to total sales, and how sales changed over time.

## 2. Business Questions

- Which regions generate the highest sales?
- Which product categories contribute most to total sales?
- How does sales performance vary by month?
- How does average sales per order line differ across categories?

## 4. Python Visual: Average Sales per Order Line

I added a Python visual to compare the mean `Sales` value for each product category. The visual uses Matplotlib and groups the records by `Category`.

```python
import matplotlib.pyplot as plt

category_summary = (
    dataset.groupby("Category", as_index=False)
    ["Sales"].mean()
)

plt.figure(figsize=(8, 5))
plt.bar(
    category_summary["Category"],
    category_summary["Sales"]
)

plt.title("Average Sales per Order Line by Category")
plt.xlabel("Category")
plt.ylabel("Average Sales per Order Line")
plt.xticks(rotation=15)
plt.tight_layout()
plt.show()
```

- The custom Python visual compares the mean sales value per order line for Furniture, Office Supplies, and Technology.

- Technology has the highest average sales per order line in the visual.

- This metric differs from total category sales: it represents the average sales value per row, not the sum of all sales in a category.
